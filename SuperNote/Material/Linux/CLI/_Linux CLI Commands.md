# Linux CLI Commands

Fundamental Linux operating system command-line utilities for file inspection, text manipulation, navigation, and identity checks.

---

## File Viewing & Text Processing
- [ ] [[cat]] - Concatenate and display the contents of files to standard output.
- [ ] [[grep]] - Search for text patterns using regular expressions across files and terminal streams.
- [ ] [[tr]] - Translate, squeeze, or delete characters from standard input.
- [ ] [[perl]] - Practical Extraction and Report Language for powerful inline text processing and one-liners.

## Navigation & File System Management
- [ ] [[ls]] - List directory contents, file attributes, permissions, and numeric UIDs.
- [ ] [[cd]] - Change the current working directory in the terminal.
- [ ] [[ln]] - Create hard and symbolic links between files and directories.
- [ ] [[mount]] - Attach storage devices, ISO images, or remote network filesystems (NFS/CIFS) to a local directory.

## Identity & Permissions
- [ ] [[whoami]] - Print the effective username associated with the current running process.
