# General OS Concepts

Foundational operating system mechanics shared across Linux administration, reverse engineering, and binary exploitation.

---

## Processes & Environment
- [ ] [[process]] - Execution model of a running binary (memory allocation, PID assignment, and OS resource scheduling).
- [ ] [[fork]] - POSIX mechanism for duplicating a running process into an identical child process with a new PID.
- [ ] [[Environment Variables]] - OS key-value configuration pairs (`PATH`, `HOME`, `USER`) accessed by processes and targeted in privilege escalation/exploits.
