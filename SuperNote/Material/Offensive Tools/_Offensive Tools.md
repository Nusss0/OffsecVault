# Offensive Tools

A curated index of specialized offensive security tools, frameworks, and exploit utilities used during penetration testing, network assessment, and binary exploitation.

---

## Network & Host Assessment
- [ ] [[Nmap]] - Industry-standard network exploration and port/service/vulnerability scanner.
- [ ] [[GoBuster]] - High-speed directory, DNS subdomain, and virtual host brute-forcing tool written in Go.
- [ ] [[searchsploit]] - Offline command-line search utility for the Exploit-DB archive.

## Windows & Active Directory Post-Exploitation
- [ ] [[CrackMapExec]] - Post-exploitation tool for Active Directory and Windows hosts to validate credentials, spray passwords, dump SAM/LSA secrets, and execute remote commands.
- [ ] [[Enum4Linux-ng]] - Next-generation information enumeration tool for Windows and Samba systems via SMB/RPC.
- [ ] [[SMBMap]] - Handy SMB share enumeration tool for auditing permissions and viewing folder contents.

## Binary Exploitation & PWN Tools
- [ ] [[checksec]] - Bash script to check executable binary security mitigations (ASLR, NX, Canary, PIE, RELRO).
- [ ] [[ROPgadget]] - Tool to search gadgets in binaries for Return-Oriented Programming (ROP) exploitation.
- [ ] [[pwntools]] - CTF framework and exploit development library in Python for rapid prototyping.
